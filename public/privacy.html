job-crm Privacy Policy

Effective November 8, 2026

job-crm is a personal tool that Astrid Xie, the owner of this website, built for herself to keep track of her own job applications. It is not offered to anyone else.

What it reads

With the owner's permission, job-crm uses the Gmail API with the gmail.metadata scope to read the labels, sender, subject line and date of messages in her own mailbox. It never reads message bodies or attachments, and it never sends, deletes or changes any email.

How the information is used

Only to update the status of the owner's job applications (for example "interview" or "rejected") in a tracker that runs on her own computer.

Where it is stored

On the owner's computer only, in a local database file. It is not uploaded to any server, not shared with or sold to anyone, not used for advertising, and not used to train AI models.

Google API Services User Data Policy

job-crm's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local files removes all stored data.
